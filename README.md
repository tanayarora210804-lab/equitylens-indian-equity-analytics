# EquityLens — Indian Equity Analytics Dashboard

EquityLens is an interactive Indian equity analytics dashboard built with Python, Dash, Plotly, Pandas, NumPy, and Yahoo Finance.

## Features

- 📊 Interactive stock price charts
- 📈 Indian equity market analysis
- 🔎 Select and analyze different stocks
- 📉 Price and performance visualization
- 🧮 Data analysis using Pandas and NumPy
- 🌐 Interactive dashboard built with Dash and Plotly
- 💹 Market data sourced using Yahoo Finance

## Technologies Used

- Python
- Dash
- Plotly
- Pandas
- NumPy
- Yahoo Finance
