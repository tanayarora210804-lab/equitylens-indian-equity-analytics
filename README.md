# EquityLens — Indian Equity Analytics Dashboard

EquityLens is an interactive Indian equity analytics dashboard built with Python, Dash, Plotly, Pandas, NumPy, and Yahoo Finance.

## Features

- 📊 Interactive stock price charts
- 📈 Indian equity market analysis
- 🔎 Select and analyze different stocks
- 📉 Price and performance visualization
- 🧮 Data analysis using Pandas and NumPy
- 🌐 Interactive dashboard built with Dash and Plotly
- 💹 Market data sourced using Yahoo Finance

## Technologies Used

- Python
- Dash
- Plotly
- Pandas
- NumPy
- Yahoo Finance

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/tanayarora210804-lab/equitylens-indian-equity-analytics.git

Move into the project directory:
cd equitylens-indian-equity-analytics

Create a virtual environment:
python -m venv .venv

Activate the virtual environment on Windows:
.venv\Scripts\activate

Install the required dependencies:
pip install dash plotly pandas numpy yfinance

▶️ Run the Dashboard

Run the dashboard using:
python dashboard.py

The application will start locally at:
http://127.0.0.1:8050/
Open the address in your browser to use EquityLens.

📊 Dashboard Analytics

The dashboard provides:
Closing Price
20-Day Moving Average
50-Day Moving Average
Trading Volume
Total Return
Annualized Volatility
Maximum Drawdown
Sharpe Ratio
Trend Signal

🎯 Project Objective
EquityLens was developed as a learning and portfolio project to explore Indian equity market data using Python.
The project combines financial data analysis, data visualization, dashboard development, and basic quantitative finance concepts into an interactive application.
